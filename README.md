# WL-NCCHSAF
A widely linear noise-constrained adaptive filtering algorithm with a non-quadratic cost function (codes)
This work focuses on the investigation of adaptive filtering algorithms under noise constraints. Its core idea lies in utilizing noise statistical information to enhance the performance of filters with nonlinear cost functions (taking the sech cost function as an example in this paper) and improve robustness. The code implementation draws inspiration from Yifei Pu's team at https://github.com/leilisc/WL-CHSAF, and we hereby express our sincere gratitude to Prof. Pu.
